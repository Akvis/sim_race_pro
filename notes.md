# Encoder 
it operates on voltages 5-20V, beware of arduino dipping to 4,5V -> encoder won't work
## pinout:
  Encoder myEncoder(2, 3);// A green ->D2, B white->D3

It differs from v1 script. OLED only display when python script is running. Debugging right pin connections on buttons is better with v1, they display directly on OLED
